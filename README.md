# Chrome Deck 2000

1. Создай на github.com **Public** репозиторий, залей в него все файлы из этой папки (Add file → Upload files).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через минуту появится ссылка `https://<ник>.github.io/<репо>/`.
3. Телефон:
   - Android (Chrome): меню ⋮ → «Установить приложение».
   - iPhone (Safari): «Поделиться» → «На экран Домой».
4. Обновления: заменяешь `index.html` в репозитории. Приложение само подтянет новую версию при следующем открытии (если играет музыка, перезагрузится после паузы).

Свои треки сохраняются на телефоне и не пропадают после обновлений.
